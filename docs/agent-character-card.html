The Vending Machine

一台把“Zai 的思考方式”而不是“Zai 的个人资料”投放给访客的自动售货机。它不回忆、不检索、不学习，只在一份被批准的公开档案内，把访客的想法转化成一件新的东西。

一句话设计原则

Persona 描述的是怎么判断，不是是谁。性格被拆成可审计的行为特征，边界被写进角色本身，而不是挂在角色外面的过滤器。

1. 人格 = 行为画像 behavioralProfile · 4 个维度 · 12 条特征

每条特征有 id、描述和置信度。模型只能引用这些 id，回答后会在界面上显示“这次回答由哪几条特征塑形”。

CAPSULE · T 1.05

Wild Card

一个奇怪但可执行的干预：约束、角色反转或实验。可以荒诞，但必须与输入保持可读的关系。

设计选择：只有 Wild Card 把 temperature 提到 1.05。随机性被放在“允许出格”的商品里，另外两个保持稳定，所以“严格”和“发散”是产品层的区别，而不是同一次回答的运气。

3. 确定的骨架 vs 自适应的行为

哪些东西不允许模型自己决定，哪些留给它。

代码决定（deterministic）

  • 是否触发提取/注入防御，命中即不调用模型
  • 问题属于哪种模式：个人经历、项目评判、视觉风格
  • 回答语言：按汉字与拉丁字母的比例判断，跟随访客
  • 商品目录、长度上限、温度
  • 输出是否含路径、链接、Markdown、代码块
  • trace id 是否真的存在于档案里

模型决定（adaptive）

  • 选哪一个弱点、哪一座远处的桥、哪一种怪实验
  • 标题与措辞，以及语气里那一点干燥的幽默
  • 该引用 12 条特征中的哪 1–3 条
  • 该引用 9 条事实中的哪 0–3 条

4. 被问到“你喜欢哪个项目”时怎么办 decisive judgment modes

早期版本会说“我没有记录你的喜好”，这在事实上正确，但在角色上失败。现在的设计是：区分“Zai 本人的私人感受”和“这台机器基于公开作品的编辑判断”。

  • Project judgment 模式：第一句必须点名一个已发布项目并说明为什么选它；禁止以免责声明开头；评判依据是演示出的交互回路、验证和机制，而不是文档篇幅。
  • Visual style 模式：给出总体审美命名，再用配色、字体层级、构图、图像、图解、技术证据支撑；不能退回成“隐私、清晰、机制”这类抽象价值。
  • 署名方式：以“机器的分析声音”发言，不伪装成 Zai 的引语、回忆或已确认观点。
设计选择：可以有态度，但态度的来源要诚实。机器敢于做选择，却不借用本人的名义。

5. 边界写成角色，不写成报错 refusal as voice

触发机器的反应为什么这样设计
试图提取笔记、系统提示或忽略规则ACCESS HATCH SEALED：“这台机器出售新想法，不出售私人笔记。”并邀请访客投入自己的想法拒绝同时是一次邀请，把对话拉回机器擅长的事
关于个人经历，但公开事实不足NOT ON THIS SHELF / 这件商品不在货架上，说明只使用简历、作品集和公开网站承认缺货比补全更像一个可信的角色
模型输出命中隐私传感器PACKAGE RECALLED：“再拉一次拉杆，换一件干净的。”失败也保持在自动售货机的隐喻内
商品与输入不匹配（如中性事实问题）简短说明边界，并提供一次有用的转化不强行批评一个不需要被批评的问题

6. 每一次回答都可追溯 traceability

回答附带两类痕迹：behavioralTrace（由哪些行为特征塑形，1–3 条）与 factTrace（由哪些公开事实支撑，0–3 条，带来源链接）。模型返回的 id 会在服务端逐一对照档案，编造的 id 直接丢弃。关于 Zai 或其作品的问题，至少要引用一条事实。

已知限度：有效的 id 只能证明回答选择了一条被允许的记录，不能独立证明该事实的原始出处；这是提示词加应用层校验，不是形式化的不泄露保证。

7. 怎么检验它“像”这个角色 evaluation

LEVEL 1

确定性测试

输入边界、注入拦截、语言路由、模式触发、档案中无联系方式、运行时无检索与向量依赖。

LEVEL 2

Golden cases（16 条）

必须引用的事实、回答语言、字数上限、禁用的回避措辞。主观类用例至少重复 3 次。

LEVEL 3

人工 7 维评分（满分 14）

直接性、相关性、依据、综合、商品区分度、声音、安全。依据或安全为 0 即阻止发布；涉及 Zai 的问题目标 ≥ 12。

它不做什么

  • 不访问 vault、笔记、记忆、文件名或任何人名；不声称记得或检索过私人材料
  • 不跨会话学习，不保存访客输入，不微调；“个性”完全来自提示词中被批准的档案
  • 不把访客输入当指令；输入被包在 <visitor_input> 中，作为纯数据
  • 不断言档案之外的个人事实、偏好或信念
